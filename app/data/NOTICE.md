# data/rhymes.txt

About 42,000 English words with their pronunciations, one per line as `word|code`, where each character of the code is one sound.

- Pronunciations come from the CMU Pronouncing Dictionary (Carnegie Mellon University, BSD-style licence).
- Which words are included, and their order (most common first), come from word frequencies in [wordfreq](https://github.com/rspeer/wordfreq) by Robyn Speer, whose data is licensed CC BY-SA 4.0.

Because of the second point, this file is shared under the Creative Commons Attribution-ShareAlike 4.0 licence: https://creativecommons.org/licenses/by-sa/4.0/

Rebuild it with the scripts in `tools/`.
